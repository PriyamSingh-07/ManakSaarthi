# ManakSaarthi

Frontend redesign of the ProcureIS Streamlit prototype.

- Branding updated to **मानकसारथी / ManakSaarthi**
- Government/enterprise procurement dashboard UI
- Recommendation, search, history, reports and profile views
- Existing `data/indian_standards.csv` and `requirements.txt` retained
- The current repository remains a frontend/demo prototype; real AI, document processing, database and BIS live-data services are not added or fabricated.
